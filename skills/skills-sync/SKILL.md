# Skills Sync

Run scripts/compare.py with Python 3 and one or more skill directories. It compares each immediate child's SKILL.md by its full SHA-256 hash. Inspect differing copies and their supporting resources before choosing a canonical version. A runtime-specific tool or model can explain a legitimate difference.
