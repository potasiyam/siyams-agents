# Gitflow

Read the repository instructions, contribution guide, and release configuration. Inspect the remote default branch, recent merged changes, tags, and CI triggers. Trace a recent change from feature branch to released revision when one exists. For a new repository, report what its configuration establishes and which conventions remain unverified. A default branch alone cannot establish the correct release target.

Report where to branch from, where to merge, the commit convention, required checks, and how a release starts. Cite a file or recent change for each claim. Flag conflicting evidence for the maintainer. Record the result in the user's project notes if requested.
