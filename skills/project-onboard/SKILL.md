# Project Onboard

Identify the remote and default branch, then read contributor instructions and the CI configuration. Follow one representative request, command, or build from its entry point to its output. Identify which module owns each step and where its behavior is tested.

Return a short guide with source paths, project-specific conventions, build and test commands, and the release path. Distinguish commands you ran from commands found in documentation. Save it at the user's chosen destination when requested.
