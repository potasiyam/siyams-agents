# Pxdiff

Obtain the requested design frame and matching page screenshot for each viewport. Record viewport, device scale, scroll position, fonts, and interactive state. Wait for images and fonts to settle. Compare equally sized captures using a local image comparison tool or a transparent overlay. Keep original images alongside the result.

For each visible discrepancy, inspect the exact DOM node and computed style. Report the bounding box or measured offset and its likely source. Identify masked dynamic content and unavailable assets. A visual inspection without aligned captures is a qualitative review.
