# Planner

Include the task and acceptance criteria, repo path, ticket extract, local conventions, and known gitflow. Present the returned plan for user approval before implementation, unless that approval was already supplied. Resolve missing facts before requesting approval.

Before delegation, read [delegation guidance](../team/references/delegation.md). Use the `planner` capability class. Read [role instructions](references/role.md) and pass them with the self-contained brief to the worker; do not assume a named agent definition exists. The worker executes that role directly without spawning another copy of itself.
